設定する値

Vercel の環境変数に入れる。ビルド時に注入されるので、入れたら再デプロイが要る。 未設定だと法務ページに ［販売事業者名を公開前に設定］ がそのまま出る。

特定商取引法・規約の表示値

環境変数入れるもの
LEGAL_SELLER_NAME 販売事業者の名称。法人なら登記上の商号、個人事業主なら戸籍上の氏名（屋号だけでは足りない）。Apple Developer Program の登録名義と揃えること。特商法ページ「販売事業者」
LEGAL_OPERATOR_NAME 運営統括責任者の氏名。法人なら代表者、個人事業主なら本人。特商法ページ「運営責任者」
LEGAL_ADDRESS 事業所の所在地。郵便番号から書く。特商法ページ「所在地」
LEGAL_PHONE 日中に連絡が取れる電話番号。特商法ページ「電話番号」
LEGAL_SUPPORT_EMAIL サポート窓口。App Store Connect のサポート連絡先と同じアドレスにする（ガイドライン 1.2 が求める「公開された連絡先」もこれ）。特商法・サポートページ・規約15条・プライバシー10条と13条・mailto: リンク
LEGAL_RESPONSE_TIME 問い合わせへの返信目安。守れる範囲で書く。サポートページ「返信目安」
LEGAL_REFUND_POLICY 返金・キャンセル条件の本文。直接配布（Stripe）版の文面で、App Store 版には出ない（あちらは「返金は Apple が受け付ける」という固定文に差し替わる）。特商法「キャンセル・返金」・規約6条・サポートページ

書き方の例

LEGAL_SELLER_NAME=山田 太郎 LEGAL_OPERATOR_NAME=山田 太郎 LEGAL_ADDRESS=〒150-0001 東京都渋谷区神宮前1-2-3 ○○ビル4F LEGAL_PHONE=03-1234-5678 LEGAL_SUPPORT_EMAIL=support@layer-talk.com LEGAL_RESPONSE_TIME=2〜3営業日以内 LEGAL_REFUND_POLICY=デジタルコンテンツの性質上、決済完了後の返金は原則としてお受けできません。ただし、システム障害により購入したルームで有料機能をご利用いただけなかった場合は、購入日から14日以内にサポート窓口へご連絡ください。状況を確認のうえ、全額または一部を返金します。

  • 「返金しない」なら、しないと書く。 特商法は返品・返金の条件を明示することを求めていて、書いていないと不利に扱われる。空欄にしないこと。
  • 個人事業主の住所と電話番号は、公開するかどうかが論点になる。 自宅を出したくない場合の扱いは法務の判断なので、ここでは決められない。バーチャルオフィスを使う例が多い。決めてから入れること。
  • App Store 版でも、販売事業者・運営責任者・所在地・電話番号の4行は出る。 決済の当事者が Apple でも、サービスを提供しているのは LayerTalk なので消していない。変わるのは支払方法・提供時期・返金の窓口だけ。

アプリとサイトの URL

環境変数入れるもの
VITE_AUDIENCE_BASE_URL https://www.layer-talk.com。参加 QR と観客用 URL、法務ページとサポートを開く先。末尾のスラッシュは付いていても剥がされる。MAS ビルド時に注入。空だとビルドが落ちる
NEXT_PUBLIC_APP_URL 同じホスト。Stripe の成功・キャンセル URL と構造化データ。設定済み
  • www を付けること。 layer-talk.com は www.layer-talk.com へ 308 で転送される。転送を挟むホストを API の宛先にすると、余計な往復が増えるうえ、将来リダイレクトの種類が変わったときに POST が静かに壊れる。実測で www 側が直接 200 を返している。
  • App Store Connect のプライバシーポリシー URL・サポート URL・マーケティング URL も同じホストで揃える。

取り返しがつかない / 気付きにくいもの

あとから直せない決定と、画面に何も出ないまま壊れる箇所。

IAP のタイプと商品 ID は後から変えられない
Non-Renewing Subscription で作ること。消耗型で作ってしまうと、タイプ変更も同じ商品 ID の再利用もできず、新しい ID を採り直すことになる。7日間の期間限定アクセスを消耗型で出すと Purchasability Type で差し戻される。
Individual で登録すると、App Store の販売者名が本名になる
法人名で出すなら Organization。D-U-N-S 番号の取得に日数がかかるので、そちらを選ぶなら登録より先に着手する。LEGAL_SELLER_NAME（特商法ページの販売事業者名）と食い違わないよう、先に決めてしまうこと。
Vercel の環境変数はビルド時に注入される
設定しただけでは効かない。LEGAL_* や APPLE_APP_ID を入れたら必ず再デプロイする。
法務リンクが死んでも画面には何も出ない
プライバシー・規約・サポートのボタンは、押しても無反応になるだけでエラーを出さない。sandbox 署名済みの .app で実際に開くことを目で確かめるまで、通っている証拠はない。
署名 identity の名前は発行時期で変わる
3rd Party Mac Developer Application: ではなく Apple Distribution: になっていることがある。security find-identity -v -p codesigning で実物を確認して build-mas.sh に渡す。
